# Windows 调用失败时如何处理

窗口在枚举后仍可能关闭，输入调用也可能只成功一部分。失败信息要描述已知事实：操作、失败阶段、系统错误以及是否可能已有部分输入。发现部分发送不要整段重试，以免重复点击或留下按下状态。

- 新增原生调用时核对返回值、错误码和资源所有权；在其他调用覆盖错误状态前读取诊断。
- 已按下但未正常结束的动作应按实际成功部分清理；清理错误不能掩盖原失败。
- 钩子观察或诊断失败不应阻断系统钩子链。截图、临时文件和图形句柄在错误路径也要释放。

回归入口：`dotnet run -c Release --project tests/KeyMouse.Tests -- --only native-input-failure,typed-dispatch`。不要用真实用户桌面复现部分注入；测试中注入受控失败即可。
