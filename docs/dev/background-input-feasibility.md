# 后台操作的可验证边界

标准编辑框和按钮可以在不激活目标的情况下操作；这不是给所有键鼠命令加一个后台开关。下表是仓库自有 WinForms 靶窗的观察结果，不代表第三方应用或全部窗口状态。独立 CLI 的 `background` 操作控件；编辑器客户区步骤则面向窗口坐标，两者不是同一机制。

## 哪些动作有证据

| 操作 | 普通非前台 | 最小化 | 实际观察与边界 |
| --- | --- | --- | --- |
| 在当前插入点写中文 | 通过 | 通过 | 向靶子编辑框定向发送 `WM_CHAR`，`A[]Z` → `A[后台]Z`，左右文字保留。不是输入法组合或全部 Unicode 的兼容性测试。 |
| Delete 单键 | 通过 | 通过 | 向该编辑框定向发按下/抬起，`A[后台]Z` → `A[后台Z`。只证明这个控件处理这个键；不证明快捷键、修饰键或按住状态。 |
| 设置编辑框完整值 | 通过 | 通过 | 原生 UIA `ValuePattern.SetValue` 后，靶子读回 `KeyMouse 后台验证`。**替换**而非插入，不应静默拿它实现 `key type`。 |
| 触发按钮 | 通过 | 通过 | `InvokePattern.Invoke` 后，靶窗实际 `Click` 事件从 0 变为 1，同名对照窗仍为 0。不是在给定像素位置按下/抬起鼠标。 |
| 拒绝错误目标 | 通过 | 通过 | 对按钮请求设置值、传入同进程另一窗的按钮、关闭靶窗后再执行：依次返回 `unsupported`、`invalid-target`、`invalid-target`。没有前台回退。 |
| 按窗口取图 | 独立像素实验通过 | 未验证 | 复跑既有 `window-isolation`：10/10 个屏幕外窗口分别读到自己的色块，关闭句柄退出码 4。这不是 OCR 准确率测试，也没有测试最小化取图。 |

**反例：** 第一版用托管 `System.Windows.Automation.ValuePattern.SetValue` 的默认路径，普通靶窗在该步骤成为前台，验证立即失败；没有继续向当时的前台投递动作。最终原型改用原生 `CUIAutomation8`，在构造客户端时将 `IUIAutomation2.AutoSetFocus` 设为 `false` 并读回核实。前一种路径不作为回退。后一种路径也不是对任意应用不抢焦点的保证：按钮的业务处理程序可能自己打开或激活窗口。

## 怎样复跑、怎样判定成功

在解锁的 Windows x64 交互桌面上，从仓库根目录运行。需要 .NET 10 桌面运行时和可构建 `net10.0-windows` 的 SDK；原型在构建时使用 .NET Framework 4.8 SDK 的 `TlbImp.exe` 从本机生成 UIA 类型定义，不需要管理员权限、签名 helper 或第三方包。实验期间请勿切换前台或移动鼠标。

```powershell
dotnet run -c Release --project tests/KeyMouse.BackgroundProbe
dotnet run -c Release --project tests/KeyMouse.Tests -- window-isolation
```

- 驱动启动自己的靶子子进程，靶子创建两个同名、内容相同的屏幕外窗口，不激活显示。普通窗口没有用 `WS_EX_NOACTIVATE` 屏蔽激活，所以能检测路径本身是否抢前台。第二组仅最小化目标，不最小化对照窗。程序不接受任意 PID/HWND。
- 每一步前后采样前台 HWND、系统光标位置；通过独立管道（重定向标准输入/输出），让靶子在 UI 线程读出实际文本、Click 次数、激活次数以及 `IsIconic`。不读取真实前台程序的内容。断言两个靶窗激活次数均为零，对照不变，目标保持原窗口状态。光标断言是检查点采样，不是全局鼠标监听。
- 实验输出 `PASS` 需要**状态实际符合预期**；不把投递成功当成执行成功。运行成功退出 0；断言失败或超时退出 1；没有可观测前台或检查点间前台/光标受干扰退出 3，本轮无结论。不会重发有副作用的动作。
- 本机 Windows build **22631**，同会话、同权限；最终版本独立构建后连续运行 **3 轮**，每轮普通、最小化两组全部通过。开发中另有一次因桌面状态变化而中止，未计为通过。原始成功输出位于本机 `artifacts/tests/background-probe-20261122T194118084Z/verified.txt`（目录时间为 UTC）。

## 如何使用这一结论

选择编辑框插入、完整替换或按钮调用时，先确认控件范围，再验证应用读回的状态。目标无法唯一识别、权限不符或不能观察效果时，报告失败或未验证。不要改用全局输入来制造成功。具体脚本和运行条件见[探针说明](../../tests/KeyMouse.BackgroundProbe/README.md)。
